# 认定标准版本比对与影响分析 Flash 成果自检

- [ ] 根字段和嵌套字段符合版本影响契约，至少包含两份独立标准原文。
- [ ] 每份标准使用独立 `S1:`、`S2:` 命名空间，未将同名规则自动等同。
- [ ] 比较顺序与排序依据一致；生成日期未被单独当作政策生效日期。
- [ ] 每条差异都含版本规则和来源定位；仅表述变化或不安全匹配已标记待人工确认。
- [ ] 无材料分支不生成材料判读；有材料分支已确认材料完整，且每个版本独立判读。
- [ ] 页面将材料判读表述为仅供审核参考，不含原审核、风险、问题或正式资格结论。
- [ ] JSON 可解析；模板唯一数据槽注入后可解析且与交付 JSON 逐字段等值。
- [ ] 用户材料与标准原文均通过 `textContent` 展示；发现秘密输入时停止且不回显。
