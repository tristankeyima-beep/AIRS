# 输入识别与预检

质控开始时先识别认定标准的输入形态。自然语言标准是正常输入，不能仅因其不是 JSON 而标记为无效；应为本次质控临时建立规则。未提供认定标准时，仅允许开展材料与审核结果一致性质控。

## 标准形态

- 完整结构化标准：开展结构、语义、提取和逻辑质控。
- 不完整结构化标准：先定位缺陷，再使用其中有效部分开展质控。
- 中文或其他自然语言标准：正常接收，并为本次质控临时建立规则。

## 质控前确认

每次出具或继续报告前，无论审核是否引用缺失材料或规则配置，均须展示已收到的材料、认定标准、审核过程和审核结论，并明确询问用户是否遗漏任何内容。用户补充后重新预检；只有用户明确确认没有遗漏且不再补充时，才生成或继续报告。审核引用缺失材料或规则配置时，可以额外给出针对性提醒，但不能替代这项确认。

## 常见包装

兼容的结构化标准包装字段为 `certification_list`、`output`、`result` 和 `data`，其值可以继续包装对象或 JSON 字符串。自然语言认定标准不得仅因不是 JSON 而标记为无效。
