# 门诊慢特病认定标准版本比对与影响分析助手（Flash）

## 技能介绍

面向医保业务、规则维护、政策管理和智能审核运营人员使用。用于对两份或以上门诊慢特病认定标准进行条件、逻辑和证据要求的可追溯比对，识别新增、删除、修改和逻辑变化；也可选用同一份申请材料，分别按各版本形成规则证据判读并比较差异。

正式交付包含结构化数据文件和离线影响分析页面。版本下的材料判读仅供审核参考，不构成最终经办资格结论。

## 它做什么

1. 分别清点每份标准的来源、版本标注、生效信息、废止或替代信息和完整原文。
2. 解析各版本的条件、提取项、逻辑关系和证据要求。
3. 建立可比条件组，避免将名称相同但含义不同的规则自动视为同一规则。
4. 识别条件新增、条件删除、条件修改、逻辑变化和仅表述变化。
5. 明确受影响审核规则和需人工复核事项。
6. 如提供并确认申请材料，则按每份标准独立形成规则证据判读和版本下参考结果，再说明变化原因。

## 用户使用流程

1. 提供两份或以上认定标准，并尽量提供版本、生效、废止或替代信息。
2. 系统逐份梳理条件与逻辑，列出会影响比较结果的歧义。
3. 用户确认标准解释、纳入范围和比较顺序。
4. 系统建立可比条件组，输出标准差异及受影响审核规则。
5. 如需材料影响分析，再提供申请材料并确认材料清单完整。
6. 系统按每份标准独立生成规则证据判读和版本下参考结果。
7. 系统交付结构化数据文件和离线影响分析页面。

## 输入与成果

| 项目 | 说明 |
|---|---|
| 主要输入 | 两份或以上认定标准；可选提供同一份申请材料 |
| 确认关口 | 标准解释、纳入范围、比较顺序；如有材料，还须确认材料完整 |
| 主要输出 | 可比条件组、标准差异、受影响审核规则、可选材料判读变化 |
| 交付成果 | 结构化数据文件 + 离线影响分析页面 |

## 使用边界与提醒

- 版本或生效信息不明确时，只输出多版本差异，不擅自判断哪一份是新标准或旧标准。
- 标准生成日期不等于政策生效日期；缺少明确依据时不会据此确定比较顺序。
- 不读取、不评价原审核结果，不使用审核质控的复核流程或问题分类。
- 未提供申请材料时，只输出标准差异，不生成材料判读。
- 发现敏感凭据或秘密配置时停止正式生成。
