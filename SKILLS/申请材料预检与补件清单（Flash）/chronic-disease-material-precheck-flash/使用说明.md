# 门诊慢特病申请材料预检与补件清单助手（Flash）

## 技能介绍

面向医保经办、医疗机构审核和申请材料受理人员使用。用于依据已确认采用的门诊慢特病认定标准，对已确认完整的申请材料逐项定位证据，形成预检结果、待补充信息和补件清单。

本助手提供申请材料预检建议，不作正式资格认定，不评价原审核结果。正式交付包含结构化数据文件和离线预检页面。

## 它做什么

1. 盘点认定标准、病种、版本、来源和患者材料。
2. 检查自然语言标准中的条件关系、阈值、单位、时长、次数、范围、排除项和来源冲突。
3. 在用户确认标准解释和材料完整后，逐项定位条件证据。
4. 将预检项标记为已定位证据、信息不足、未定位证据或材料形式待确认。
5. 将待处理项转为补充信息或补件清单，并说明原因、建议动作和优先查找位置。

## 用户使用流程

1. 提供认定标准和患者申请材料；标准可为已确认的结构化标准、自然语言标准或已确认的知识库检索结果。
2. 系统梳理影响结果的标准歧义；存在关键歧义时，请用户先确认。
3. 用户确认采用的标准、版本和规则解释。
4. 系统展示材料清单；用户明确确认材料完整。
5. 系统逐项定位证据，生成预检结果、补充信息与补件清单。
6. 系统交付结构化数据文件和离线预检页面。

## 输入与成果

| 项目 | 说明 |
|---|---|
| 主要输入 | 已确认标准、患者申请材料 |
| 确认关口 | 标准采用与材料清单均须明确确认 |
| 主要输出 | 条件—证据预检、补充信息、补件清单、待人工确认项 |
| 交付成果 | 结构化数据文件 + 离线预检页面 |

## 使用边界与提醒

- 不输出“通过”或“不通过”结论，不构成正式资格审核结论。
- 未定位证据只表示当前材料中尚未定位到对应信息，不表示患者未提交材料。
- 标准未规定可接受的材料形式时，只能提示人工确认，不能凭空指定诊断证明、检查单等特定文件。
- 已定位证据的条件不会进入补件清单。
- 只使用用户提供并确认的标准、材料和解释；发现敏感凭据或秘密配置时停止正式生成。
