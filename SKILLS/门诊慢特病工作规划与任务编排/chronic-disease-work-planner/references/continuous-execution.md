# 执行模式与状态控制

## 只制定计划

- 只完成意图识别、输入盘点、任务拆解、能力选择、依赖和预期成果。
- 不调用任何下游能力。
- 后续步骤保持 `⬜ 计划执行`；不能因为本轮没有执行而标记为 `❌`。

## 自动连续执行

自动连续执行必须遵循以下顺序：

1. 用户选择“自动连续执行”。
2. 展示完整工作计划，包括步骤、使用能力、依赖、确认门和预期交付物。
3. 用户明确确认按完整工作计划开始。
4. 按计划顺序调用必要能力，并把上一步的正式成果传给下一步。
5. 没有确认门时，不反复询问用户是否继续。
6. 遇到确认门时暂停，在计划之外提出详细问题；用户回答后，从暂停点恢复。
7. 当结果改变原定路线时，只重新规划受影响的步骤；发生重大变化时，再次展示调整后的计划并请求确认。
8. 结束时，实际执行过的步骤必须收敛为 `✅ 已完成` 或 `❌ 未完成`；失败步骤必须说明原因。

自动连续执行不等于调用全部能力，不替用户确认任何业务判断，不补造输入、事实或下游成果，也不改变用户已经确认的目标。

## 必须暂停的业务关口

出现以下任一情况时必须暂停，不得自行越过：

- **认定标准选择**：存在多份候选标准、标准来源不明确或适用标准尚未由用户选定。
- **规则解释**：规则存在歧义，或其业务含义会影响后续材料、审核或质控结论。
- **认定标准草案确认**：生成或修改后的认定标准草案必须由用户确认后，才能作为后续步骤的输入。
- **材料完整性**：是否接受缺项、替代材料或现有材料范围，必须由用户确认。
- **版本顺序**：现行版、历史版和拟修订版的比较或应用顺序尚未确认。
- 缺输入，且缺失内容会影响能力调用、事实判断或交付物质量。
- 下游失败，或下游没有返回可供下一步使用的正式成果。
- 发生重大重新规划，包括目标、核心输入、适用标准、能力路线或主要交付物发生变化。

## 省局内网授权

知识问答应用是已授权内部应用，部署在**省局内网**。用户确认“自动连续执行”与“完整工作计划”后，可以在已经确认的计划范围内，把患者原始材料传给知识库检索及其他内部能力，无需重复询问隐私授权。

该授权只覆盖已确认计划范围内的省局内部应用调用，不覆盖其他外部服务或任何计划外发送，也不能绕过下游 Skill 对敏感凭据的停止处理。认定标准选择、规则解释、材料完整性、版本顺序仍必须由用户确认。

## 暂停、恢复与重新规划

- 暂停时，立即把当前步骤更新为 `⏸️ 等待确认或补充`，并在工作计划中记录简短原因。
- 详细问题必须放在计划之外；计划内只保留问题摘要、受影响步骤和确认后的动作。
- 用户回答后，先更新对应步骤的状态和已确认输入，再从暂停点恢复连续执行。
- 恢复或重新规划时，保留所有已完成步骤及其交付物，不重复执行无关步骤。
- 新信息只影响部分路线时，只修改受影响的后续步骤，其余计划保持不变。
- 目标、核心输入、适用标准、能力路线或主要交付物发生重大变化时，必须展示调整后的完整工作计划并再次获得用户确认。
