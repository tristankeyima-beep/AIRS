# 慢病知识库检索

1. 将包含本 `SKILL.md` 的目录解析为绝对路径 `<SKILL_ROOT>`。不要执行 `cd`，不要依赖当前工作目录或仓库根目录。
2. 判断任务类型。仅在配置或部署时读取 `<SKILL_ROOT>/references/internal-deployment.md`，不执行检索。若用户已提供完整依据并明确只要求改写、排版或计算，也不执行检索。除此之外，符合本 Skill 范围的知识问题必须固定调用一次，不得凭模型记忆跳过。
3. 保留用户的原始问题，不改写、不拆分。将 `<SKILL_ROOT>` 替换为实际绝对路径，只执行一次：

   ```bash
   python3 "<SKILL_ROOT>/scripts/query_adp.py" --config "<SKILL_ROOT>/config/adp-config.json" --query "<原始问题>"
   ```

4. 分别读取返回 JSON 中的 `answer`、`knowledge` 和 `workflow`，不要把三者混成一个字段。
5. 由当前调用模型依据检索结果继续解释、比较或完成业务处理。来源缺失时明确说明缺失，不补造来源、标题、版本或链接。
6. 检索失败时不要依靠模型记忆编写知识依据。区分并说明：配置文件或环境变量缺失为“未配置”，认证错误或 HTTP 401/403 为“鉴权失败”，网络、超时或 SSE 错误为“不可访问”，空结果为“检索无结果”。
7. 将检索结果作为知识依据，不直接当作患者诊断，也不直接当作最终医保资格结论。
