# 代码节点出入参说明：提取相关性最高的知识库结果

对应代码：`代码-提取相关性最高的知识库结果.py`

## 节点职责

从 ADP 知识库检索结果中选择相关性最高的一条有效 DOC，仅把它的正文 `Content` 输出为 `knowledgeContent`，供后续 LLM 生成 `ruleRepository` 与 `logicTopology`。

本节点不判断病种名称、不拼接多条检索内容、不保留 QA，也不生成规则。

## 入参

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `knowledge_result` | `obj` 或 `str` | 是 | ADP 知识库检索节点的完整 Output；也兼容 JSON 字符串及腾讯的 `Output`、`input`、`params` 等参数外层包装。 |

### 输入层级

```text
knowledge_result: Object
  KnowledgeList: Array
    - item: Object
        KnowledgeType: String，必须为 DOC 才参与选择
        Content: String，必须非空
        Confidence: Number 或可转为 Number 的字符串
```

## 选择规则

1. 只保留 `KnowledgeType="DOC"` 的条目。
2. 忽略 `Content` 为空、`Confidence` 缺失、不能转成数字、为无穷或 NaN 的条目。
3. 选取 `Confidence` 最高的候选。
4. 最高分相同，保留 `KnowledgeList` 中最先出现的一条。
5. QA 条目即使置信度更高也不参与选择。

没有有效 DOC、输入 JSON 无法解析或 `KnowledgeList` 不是数组时，代码节点抛出 `ValueError`，不向 LLM 传递空上下文。

## 出参

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `knowledgeContent` | `str` | 最高相关 DOC 的完整 `Content`，去除首尾空白。 |

腾讯平台输出 Schema：

```text
knowledgeContent: str
```

## 腾讯平台配置

代码节点输入：

```text
knowledge_result = ADP 知识库检索节点 Output
类型 = obj
```

下游 LLM 节点输入：

```text
knowledgeContent = 本代码节点 knowledgeContent
类型 = str
```

## 可直接粘贴测试的入参

```json
{
  "knowledge_result": {
    "KnowledgeList": [
      {
        "KnowledgeType": "QA",
        "Content": "不应选择，即使置信度最高",
        "Confidence": 0.99
      },
      {
        "KnowledgeType": "DOC",
        "Content": "文档名：癫痫-认定标准-v20260517",
        "Confidence": 0.6437201
      },
      {
        "KnowledgeType": "DOC",
        "Content": "文档名：尿毒症透析-认定标准-v20260517",
        "Confidence": 0.8122648
      }
    ]
  }
}
```

## 对应出参示例

```json
{
  "knowledgeContent": "文档名：尿毒症透析-认定标准-v20260517"
}
```

## 联调定位

| 现象 | 原因与处理 |
| --- | --- |
| `未找到 Content 非空且 Confidence 有效的 DOC 知识库结果` | 检索结果没有有效 DOC，检查检索节点返回、`KnowledgeType` 和 `Confidence`。 |
| `knowledge_result 中未找到 KnowledgeList 数组` | 代码会自动拆 `Output`、`input`、`params` 等常见平台包装；若仍报错，按错误中的“当前对象字段”检查实际绑定层级。 |
| LLM 仍收到多个病种内容 | LLM 输入应绑定本节点 `knowledgeContent`，不能再绑定 ADP 原始 Output。 |
