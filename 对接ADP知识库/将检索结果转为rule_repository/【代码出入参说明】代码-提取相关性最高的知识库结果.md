# 代码节点出入参说明：提取相关性最高的知识库结果

对应代码：`代码-提取相关性最高的知识库结果.py`

## 节点职责

从 ADP 知识库检索结果中选择相关性最高的一条有效 DOC，仅把它的正文 `Content` 输出为 `knowledgeContent`，供后续 LLM 生成 `ruleRepository` 与 `logicTopology`。

本节点会以当前备案病种名称筛选检索正文，不拼接多条检索内容、不保留 QA，也不生成规则。

## 入参

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `knowledge_result` | `obj` 或 `str` | 是 | ADP 知识库检索节点的完整 Output；也兼容 JSON 字符串及腾讯的 `Output`、`input`、`params` 等参数外层包装。 |
| `chronicDiseaseName` | `str` | 是 | 当前备案病种名称。只有 `Content` 包含该名称的 DOC 才参与相关性排序。 |

### 输入层级

```text
knowledge_result: Object
  KnowledgeList: Array
    - item: Object
        KnowledgeType: String，必须为 DOC 才参与选择
        Content: String，必须非空
        Confidence: Number 或可转为 Number 的字符串
```

## 选择规则

1. 只保留 `KnowledgeType="DOC"` 的条目。
2. 只保留 `Content` 包含 `chronicDiseaseName` 的条目。
3. 忽略 `Content` 为空、`Confidence` 缺失、不能转成数字、为无穷或 NaN 的条目。
4. 选取 `Confidence` 最高的候选。
5. 若没有正文包含病种名称的有效 DOC，输出 `knowledgeContent=""`、`documentName=""`。
6. 最高分相同，保留 `KnowledgeList` 中最先出现的一条。
7. QA 条目即使置信度更高也不参与选择。

没有有效 DOC、输入 JSON 无法解析或 `KnowledgeList` 不是数组时，代码节点抛出 `ValueError`，不向 LLM 传递空上下文。

## 出参

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `knowledgeContent` | `str` | 最高相关 DOC 的完整 `Content`，去除首尾空白。 |
| `documentName` | `str` | 最高相关 DOC 的文档名，优先取 `DocName`，缺失时从正文首行 `文档名：...` 解析。 |

腾讯平台输出 Schema：

```text
knowledgeContent: str
documentName: str
```

## 腾讯平台配置

代码节点输入：

```text
knowledge_result = ADP 知识库检索节点 Output
类型 = obj

chronicDiseaseName = 根据 certification_list 获取备案病种.chronicDiseaseName
类型 = str
```

下游 LLM 节点输入：

```text
knowledgeContent = 本代码节点 knowledgeContent
类型 = str
```

最终“组装 certification_list”节点应绑定本节点的 `documentName`，用于生成 `meta.version`。

## 对应出参示例

```json
{
  "knowledgeContent": "文档名：尿毒症透析-认定标准-v20260517",
  "documentName": "尿毒症透析-认定标准-v20260517.md"
}
```

## 联调定位

| 现象 | 原因与处理 |
| --- | --- |
| `knowledgeContent` 为空 | 没有正文包含当前 `chronicDiseaseName` 的有效 DOC；下游应停止生成规则或走检索兜底分支。 |
| `chronicDiseaseName 必须是非空字符串` | 代码节点没有绑定备案病种名称。 |
| `knowledge_result 中未找到 KnowledgeList 数组` | 代码会自动拆 `Output`、`input`、`params` 等常见平台包装；若仍报错，按错误中的“当前对象字段”检查实际绑定层级。 |
| LLM 仍收到多个病种内容 | LLM 输入应绑定本节点 `knowledgeContent`，不能再绑定 ADP 原始 Output。 |
