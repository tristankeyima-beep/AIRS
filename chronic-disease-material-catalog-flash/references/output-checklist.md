# 材料证据编目与归位 Flash 成果自检

## 通用

- [ ] JSON 可解析，不含注释或尾逗号，根字段恰好符合 `material_catalog` 契约。
- [ ] 每份输入材料各对应一条 `sourceDocuments`，完整原文已保存，未合并、摘要、截断或改写。
- [ ] 用户已明确确认材料完整；`confirmation.inventoryShown` 与来源材料名称的顺序和内容完全一致。
- [ ] `analysisRecord` 是可审阅的编目说明，结论明确不构成资格、材料充分性或审核结论。
- [ ] 无规则判断、资格结论、审核结论、风险、问题或建议字段；页面没有审核语义。
- [ ] 疑似秘密已触发立即停止；脱敏告警不含具体值，且没有回显、记录或上传秘密。
- [ ] 外部发送已同时确认目标服务或地址、具体动作和材料范围；任一项不清楚时仍保持本地处理。

## 编目与归位

- [ ] `catalog` 与 `sourceDocuments` 一一对应且顺序一致。
- [ ] 每条事实仅摘录原文明确内容，`sourceReference` 可回指同一来源材料；未定位时不伪造页码、段落或事实。
- [ ] `readability=无法编目` 的材料没有事实摘录，并写明待核对原因。
- [ ] 只有原文明确到日的日期进入已确认时间线；待核对日期项目在已确认项目之后。
- [ ] 每份材料在时间线中恰好出现一次。
- [ ] 每条材料关系都引用已有材料、具有原文依据；疑似重复一律为待核对，未删除或合并来源材料。

## HTML

- [ ] HTML 使用 `assets/material-catalog-template.html`。
- [ ] 替换前，模板 `flash-data` 数据槽中 `__FLASH_DATA_JSON__` 占位符恰好出现一次。
- [ ] 从已序列化且自检通过的 JSON 开始，仅转义字面 `<`、`>`、`&` 后替换数据槽一次。
- [ ] 替换后，数据槽不再是纯占位符、可解析为 JSON，且与交付 JSON 逐字段等值。
- [ ] 模板 CSS 和 JavaScript 未被修改；HTML 的目录、时间线、关系、待核对项和来源材料均来自 JSON。
- [ ] 页面不直接展示英文状态码，用户材料以 `textContent` 写入页面。
